# D3 우주의 N차원 구조분열 전구조 교환, 축성긴장, 팽창 및 구조적 고립 시뮬레이션

## 1. 시뮬레이션 범위

이번 계산은 고랭크 우주의 형성과 붕괴를 재현하지 않는다.
기초 우주는 처음부터 끝까지 D3로 고정한다.

```txt
N_base = 3
```

교차채널 4, 5, 6은 추가 차원축이 아니다.
그것들은 N차원 구조분열 전구조와 D3 우주 사이의 고랭크 교환 경로를 D3의 세 축에 투영한 계산 채널이다.

```txt
전구조 고랭크 에너지
→ 교차채널 q
→ D3 축성긴장 및 등방·비등방 이완
→ 계량 팽창·수렴
→ 입자의 연결성 및 운동 응답
```

기본 시나리오에서는 고랭크 에너지가 입자에 직접 주입되지 않는다.
입자는 D3 축성긴장, 척도인자, 팽창속도, 수렴 및 연결성 변화를 통해 간접적으로만 반응한다.

## 2. 상태량

### 2.1 전구조와 교차채널

전구조 에너지 저장량을 `E_pre`, 교차채널 q의 연결·고립 에너지를 각각 `E_q_conn`, `E_q_iso`로 둔다.

유입은 채널별로 계산한다.

```txt
Phi_in,q >= 0
```

팽창에 의해 채널 분리속도가 정보전파 상한을 넘으면 연결 에너지가 고립 에너지로 이동한다.

```txt
v_sep,q = H a L_q
v_sep,q / c_info,q > 1
```

### 2.2 D3 축성긴장

D3 축성긴장은 대각 성분으로 기록했다.

```txt
T_D3 = diag(tau_x, tau_y, tau_z)
```

고랭크 유입이 D3로 간접 전달되면 해당 투영축의 긴장이 이완되고, 유출이 일어나면 해당 축의 수렴 긴장이 증가한다.

```txt
d tau_i / dt
= - k_in,T I_i
  + k_out,T O_i
  + k_eq (mean(tau)-tau_i)
  + k_restore (tau_0-tau_i)
```

등방 성분과 편차 성분은 다음으로 측정했다.

```txt
mean axial tension = mean(tau_x, tau_y, tau_z)
axial-tension deviation = std(tau_x, tau_y, tau_z)
```

### 2.3 팽창과 수렴

팽창률은 연결된 등방 이완에너지, 평균 긴장 이완, 유출에 의해 형성된 수렴 기억, 축성긴장 편차를 함께 사용했다.

```txt
dH/dt
= lambda_rel R_conn
  - lambda_conv C_out
  - lambda_aniso sigma_T
  - gamma_H H
```

```txt
da/dt = H a
N_e = ln a
```

이는 현상론적 구조응답식이며 Friedmann 방정식의 유도가 아니다.

### 2.4 입자 반응

기본 시나리오에서 정의역 직접 겹침은 0으로 두었다.

```txt
particle_domain_overlap_q = 0
```

따라서 모든 기준군에서 직접 입자 유입량은 정확히 0이다.
입자 반응은 팽창률, 팽창률 변화, 축성긴장 편차 및 축성긴장 변화율을 이용한 간접 응답 proxy로만 기록했다.
이 proxy는 에너지 관측량이 아니다.

## 4. 주요 비교

### 4.1 직접 입자 충격의 부재

네 기준군 모두 다음이 성립했다.

```txt
total_direct_particle_import = 0
```

그러나 간접 입자 응답 proxy는 0이 아니었다.

```txt
대칭 등방군           4.296629
단일축 편향군         4.826378
유출 우세군           3.727926
급팽창 고립군         6.272481
```

따라서 이 구성에서는 고랭크 에너지의 큰 총량이 입자에 직접 투입되지 않아도, D3 구조의 팽창·수렴·축성긴장 변화로 인해 입자 연결성과 운동조건은 크게 바뀐다.

### 4.2 고립 순서

모든 기준군에서 교차채널 고립이 입자 고립보다 먼저 나타났다.

```txt
대칭군      0.652 tau 선행
비등방군    0.728 tau 선행
유출군      0.776 tau 선행
급팽창군    0.506 tau 선행
```

이는 더 긴 대표척도와 더 낮은 정보전파 상한을 부여한 고랭크 교차채널이 D3 입자계보다 먼저 전역 연결을 잃는다는 현재 구성의 결과다.

### 4.3 기초 차원 랭크

모든 시간점과 모든 기준 시나리오에서 다음이 유지됐다.

```txt
base_dimension = 3
```

활성 교차채널 수와 연결 교차채널 수는 변했지만 우주의 기초 랭크는 변하지 않았다.

## 7. 이번 계산에서 나타난 구조적 결과

```txt
1. D3 우주는 고랭크 교차채널이 활성화돼도 기초 랭크 3을 유지할 수 있다.

2. 고랭크 유입은 입자에 직접 고에너지를 주입하지 않고도
   D3 축성긴장과 계량을 통해 큰 간접 효과를 만들 수 있다.

3. 대칭 유입은 등방 팽창으로 효율적으로 전환되지만,
   단일축 편향 유입은 축성긴장 편차에 더 많이 남는다.

4. 유출은 즉시 수축을 만들기보다 수렴 기억을 누적하며,
   초기 팽창 뒤 지연된 수렴을 만들 수 있다.

5. 팽창은 입자보다 고랭크 교차채널을 먼저 고립시킬 수 있다.

6. 교차채널 고립은 우주의 차원 붕괴가 아니라
   전구조 교환경로의 연결성 상실이다.
```

## 8. 지위와 남은 정의

이번 결과는 조건부 수치 구성이다.
다음 항은 아직 물리 상수나 관측량으로 고정되지 않았다.

```txt
축성긴장과 실제 계량 사이의 변환계수
전구조 교차채널의 실제 정보전파 상한
교차채널 대표척도
유입·유출률의 물리 단위
수렴 기억의 미시적 정의
입자 간접 응답 proxy와 실제 운동량·에너지 사이의 변환
```

이번 계산에서 결정된 것은 위 계수의 실제 값이 아니라, 사용자가 제시한 교환 규칙을 모순 없이 분리했을 때 나타나는 경로 구조다.
