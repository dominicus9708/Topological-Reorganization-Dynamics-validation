## 1. 모델 지위

이 계산은 형성공리계 또는 속성공리계에서 유도된 정리가 아니다.
D5 직접붕괴 모형의 조건부 구성을 D6으로 확장하여, 실현 랭크가 보존되지 않을 수 있는 경로를 비교한 탐색적 수치 구성이다.

구조분열 전구조는 제7차원이나 유한한 외부 벌크로 두지 않았다.
전구조는 특정 유한 랭크로 닫히기 전의 N차원 후보·교환 레짐이다.
`N_prestructure_drive`는 그 레짐과의 결합 구동을 정규화한 항이며, 물리적 경계면의 면적 플럭스가 아니다.

## 2. D6 확장 기준

D5 모형의 쌍별 잔차를 세 쌍으로 확장했다.

```txt
sigma_ij = sqrt(q_i q_j) (1-rho_ij),  ij in {45,46,56}
```

세 추가축의 공동 독립성은 Gram 행렬로 검사했다.

```txt
G_ii = q_i
G_ij = sqrt(q_i q_j) rho_ij
nu_456 = sqrt(det G_456)
```

이 단계에서 두 판정법을 분리했다.

```txt
A. D5 계승 결합채널 제거 구성
   중복 임계와 D3 닫힘 조건이 동시에 만족되면
   결합된 추가축 채널을 같은 사건에서 제거한다.

B. 엄격 Gram 실현랭크 판정
   중복은 독립성의 감소로만 읽고,
   남은 공통 방향의 소멸은 별도 랭크 사건으로 판정한다.
```

두 판정은 같은 명제가 아니다.

## 3. D5 계승 결합채널 제거 구성

기준 시나리오 결과:

```txt
symmetric_direct : D6 -> D3, t/tau = 1.776
pair_dominant_45 : D6 -> D4 -> D3
single_dominant_6: D6 -> D5 -> D3
no_overlap_control: D6 유지
```

대칭 기준군은 세 쌍의 독립 잔차와 삼중 방향체적 잔차가 임계 이하가 되고 D3 닫힘 조건이 성립한 시점에 제4·5·6축 채널을 같은 사건에서 제거했다.
이 의미에서는 활성 채널 기록상 D6->D3 직접 전이가 성립했다.

그러나 사건 직전 Gram 고유값을 확인하면 추가축의 엄격 실현랭크는 1이었다.
따라서 이 결과를 곧바로 “기하학적으로도 중간 D4가 전혀 없다”고 읽을 수는 없다.

125개 매개변수 격자:

```txt
D6_to_D4_pair_45 -> D4_to_D3_single_6                          56
D6_to_D5_single_4 -> D5_to_D4_single_5 -> D4_to_D3_single_6    28
D6_to_D3_direct_triple                                         21
D6_to_D4_pair_45                                               15
none                                                            5
```

이는 확률이 아니라 명시된 격자의 셀 수이다.

## 4. 엄격 Gram 실현랭크 감사

축별 닫힘을 독립방향의 유효 진폭으로 포함했다.

```txt
a_i(t) = q_i [1-eta_i(t)]
G_eff,ii = a_i
G_eff,ij = sqrt(a_i a_j) rho_ij
N_realized(t) = 3 + rank_epsilon(G_eff)
```

대칭 기준군:

```txt
D6 -> D4 at 1.216 tau
D4 -> D3 at 3.124 tau
```

첫 사건에서는 세 추가축이 하나의 공통 방향으로 퇴화했다.
두 번째 사건에서는 그 공통 방향의 유효 고유값도 임계 아래로 내려갔다.
따라서 엄격 랭크 기준에서는 중복과 소멸이 분리된다.

비대칭 기준군:

```txt
pair_dominant_45:
D6 -> D5 at 1.094 tau
D5 -> D4 at 1.402 tau
D4 -> D3 at 3.122 tau

single_dominant_6:
D6 -> D5 at 1.072 tau
D5 -> D4 at 1.216 tau
D4 -> D3 at 2.890 tau

no_overlap_control:
D6 유지
```

엄격 랭크 125개 격자:

```txt
D6 -> D5 -> D4 -> D3    48
D6 -> D5 -> D4          31
D6 -> D3                20
D6 -> D4 -> D3          12
D6 -> D4                 8
D6 유지                  5
D6 -> D5                 1
```

엄격 모형에서도 D6->D3 동시 랭크 소멸 셀이 존재했다.
다만 대칭 중복 기준군의 직접 채널 제거와 같은 메커니즘이 아니라, 세 유효 고유값이 같은 시간간격에서 모두 임계 아래로 내려간 경우이다.

## 5. 수치수렴 및 장부

D5 계승 직접 채널 제거 구성의 기준 사건은 시간간격 감소에 따라 다음처럼 수렴했다.

```txt
dt      event time/tau
0.0080  1.7680
0.0040  1.7720
0.0020  1.7760
0.0010  1.7760
0.0005  1.7765
```

정규화된 붕괴량은 내부 잔류 0.55, 전구조 유출 0.30, 소산 0.15로 분배했으며 장부 오차는 0이었다.
이 분배율은 물리 상수가 아니라 D5 모형의 내부 잔류·전구조 교환 구분을 보존하기 위한 기준 매개변수다.

D5 기준사건과 같은 1.776 tau는 D5의 중복 사건을 기준으로 중복 구동률을 보정했기 때문이다.
이는 D6의 독립적인 자연상수가 아니다.

## 6. 핵심 해석

```txt
형식적 D6
!= 독립성이 유지되는 실현 D6
!= 내부 관찰자가 접근할 수 있는 D6

추가축 사이의 중복
!= 추가축 전체의 소멸

결합 채널의 동시 제거
!= 엄격 Gram 랭크가 중간값을 갖지 않음
```

이번 계산에서 가장 중요한 결과는 D6가 D3로 내려갈 수 있다는 단일 사례가 아니다.
랭크 감소가 직접·쌍별·단일축 경로로 분기하며, 어떤 판정 개념을 쓰는지에 따라 같은 수치 상태의 전이명이 달라진다는 점이다.

전구조가 N차원 후보 레짐이라는 사실은 D6 바깥에 물리적 D7 벌크가 있다는 뜻이 아니다.
붕괴축의 유출은 특정 외부 표면을 통과하는 것으로 계산하지 않고, 닫히지 않은 구조분열 전 레짐과의 구성적 교환으로 기록했다.

## 7. 입증되지 않은 것

```txt
D6는 반드시 D3로 붕괴한다.
D3가 유일한 안정 랭크다.
중복만으로 축의 완전 소멸이 증명된다.
실제 고차원 공간이 이 식을 따른다.
전구조의 N차원성이 물리적 무한차원 공간을 뜻한다.
이 계산이 우주 초기의 차원 선택을 재현한다.
```

## 8. 다음 정식화 대상

이번 감사로 다음 정의가 필요해졌다.

```txt
1. 축 독립성 상실
2. 축들의 하나의 공통 방향으로의 합류
3. 그 공통 방향의 D3 닫힘 구조로의 흡수
4. 채널 부재 또는 완전 소멸
```

D5의 직접붕괴 명칭도 이 네 상태를 기준으로 재검토해야 한다.
현재 D6 결과는 “랭크 비보존의 조건부 가능성”을 지지하지만, 직접붕괴의 엄격한 정의는 아직 닫히지 않았다.
