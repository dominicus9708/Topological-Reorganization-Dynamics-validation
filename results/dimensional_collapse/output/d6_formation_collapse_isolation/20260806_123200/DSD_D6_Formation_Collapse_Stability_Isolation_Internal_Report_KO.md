## 1. 목적과 범위

이 계산은 기존 D6 축–법선 중복 및 엄격 Gram 랭크 파이프라인을 형성 이전과 붕괴 이후까지 확장한다.

추적 대상은 다음과 같다.

```txt
형성:
구조분열 전구조에서 명시적 고랭크 채널 D4, D5, D6으로 들어오는 에너지

붕괴:
국소 실현 랭크와 전역 연결 랭크의 분리
붕괴 해방량과 내부 배분

팽창:
척도인자, 체적계수, 팽창률, 누적 e-fold, 가속팽창 구간

고립:
팽창속도가 정보전파 상한을 넘을 때
입자 에너지와 랭크 부여 에너지가 연결 구획에서 고립 구획으로 이동하는 과정

안정·소멸:
고랭크 유지, D3 안정화, 장기 완화, 형성 사건의 에너지 소멸
```

구조분열 전구조는 D7 벌크로 놓지 않았다.
전구조는 특정 유한 랭크로 닫히기 전의 N차원 후보·교환 레짐이며, 에너지는 유한한 정규화 저장량으로 둔다.
전구조의 N차원성은 무한 에너지를 뜻하지 않는다.

## 2. 측정식

전구조에서 고랭크 채널로 들어오는 유입률은

```txt
J_in = k_in F(t) E_pre [1 - E_high / E_cap]_+
```

으로 두었다.

고랭크 연결 구획에서 전구조로 돌아가는 유출률은

```txt
J_out = k_out O(t) E_high,connected
```

으로 두었다.

국소 실현 랭크는 연결·고립 고랭크 에너지를 모두 포함한 Gram 행렬에서 계산한다.
전역 연결 랭크는 연결 구획의 에너지만 사용한다.

```txt
N_local = 3 + rank_epsilon(G_total)
N_connected = 3 + rank_epsilon(G_connected)
```

따라서

```txt
N_local > N_connected
```

이면 추가 방향이 국소적으로는 남아 있지만 전역 교환망에서는 고립된 상태를 뜻한다.

팽창률은 물리적 Friedmann 방정식이 아니라 정규화된 투영식으로 두었다.

```txt
H(t) = lambda_H sqrt[E_exp / (a^3 + V_0)]
da/dt = H a
N_e = ln a
```

입자 및 랭크 에너지의 대표 팽창속도는

```txt
v_exp,p = H a ell_p
v_exp,r = H a ell_r
```

이며, 각각의 정보전파 상한과 비교한다.

```txt
x_p = v_exp,p / c_info,p
x_r = v_exp,r / c_info,r
I(x) = x^m / (1 + x^m)
```

`x=1`은 고립 전환의 기준이지 실제 우주의 관측된 임계값이 아니다.

## 3. 기준 시나리오 결과

### 3.1 균형 다단계군

```txt
형성: D3 -> D4 -> D5 -> D6
최종: 국소 D3 / 연결 D3, 안정
전구조 총유입: 4.723254
고랭크 총유출: 0.534912
순유입: 4.188342
붕괴 해방량: 4.184724
최종 척도인자: 3.818324
누적 e-fold: 1.339811
최대 H: 0.283413
최종 입자 고립률: 0.326549
최종 랭크 부여 에너지 고립률: 0.957443
```

랭크 에너지의 팽창속도는 3.904 tau에서 정보전파 상한을 넘었다.
연결 D4->D3 전이는 4.806 tau, 국소 D4->D3 붕괴는 5.284 tau였다.
따라서 최종 추가방향은 국소 소멸보다 0.478 tau 먼저 전역 연결성을 잃었다.

### 3.2 강한 팽창·고립군

```txt
형성: D3 -> D4 -> D5 -> D6
최종: 국소 D3 / 연결 D3, 완화 중
전구조 총유입: 4.834887
고랭크 총유출: 0.430247
순유입: 4.404640
붕괴 해방량: 4.400716
최종 척도인자: 5.226009
누적 e-fold: 1.653648
최대 H: 0.388562
최종 입자 고립률: 0.712407
최종 랭크 부여 에너지 고립률: 0.990774
```

랭크 고립 임계는 3.442 tau에 먼저 나타났다.
그 뒤 연결 랭크는 3.636 tau에 D6->D5, 3.710 tau에 D5->D4로 내려갔다.
국소 랭크 붕괴는 각각 3.734 tau와 3.834 tau였다.

연결 D4->D3 전이는 4.516 tau였지만 국소 D4->D3 붕괴는 5.314 tau였다.
즉, 마지막 추가방향은 국소적으로 약 0.798 tau 더 남아 있으면서 전역 연결망에서는 먼저 고립되었다.

입자 팽창속도는 4.574 tau에 정보전파 상한을 넘었다.
최종적으로 입자 에너지 약 71.2%, 랭크 부여 에너지 약 99.1%가 고립 구획에 남았다.

### 3.3 유출·소산 소멸군

```txt
형성: D3 -> D4 -> D5 -> D6
최종: 국소 D3 / 연결 D3
형성 사건 소멸 시각: 8.344 tau
전구조 총유입: 4.494915
고랭크 총유출: 1.613947
순유입: 2.880968
붕괴 해방량: 2.880968
누적 e-fold: 0.646017
최종 형성사건 에너지: 0.000434
```

이 시나리오의 소멸은 기초 D3 운반구조의 소멸을 뜻하지 않는다.
전구조에서 유입되어 형성되었던 고랭크·입자·팽창 사건의 잔류 에너지가 임계 아래로 내려간 것을 뜻한다.

### 3.4 고랭크 안정 유지군

```txt
형성: D3 -> D4 -> D5 -> D6
최종: 국소 D5 / 연결 D5, 안정
순 고랭크 유입: 4.406173
붕괴 해방량: 0.059827
누적 e-fold: 0.116560
입자 고립률: 0.000003
랭크 부여 에너지 고립률: 0.000136
```

약한 중복·닫힘과 낮은 팽창 결합에서는 하나의 추가방향이 상실된 뒤 D5가 국소·연결 양쪽에서 유지되었다.
고랭크 존재가 자동으로 강한 팽창이나 고립을 일으키지는 않았다.

## 4. 125개 매개변수 격자

```txt
최종 국소 D3 / 연결 D3: 76개
최종 국소 D4 / 연결 D3: 24개
최종 국소 D4 / 연결 D4: 13개
최종 국소 D5 / 연결 D4: 12개
```

총 36개 셀에서

```txt
N_local > N_connected
```

가 나타났다.
이는 팽창 고립을 포함하면 전역 연결 랭크가 국소 실현 랭크보다 낮아질 수 있음을 보인 조건부 구성이다.

격자 전체의 누적 e-fold 범위는 0.338382–1.689409였다.
최대 격자점에서도 60 e-fold에 근접하지 않았다.
따라서 이번 계산은 인플레이션을 재현한 결과가 아니다.

격자 최종 입자 고립률은 0.000294–0.711270, 랭크 부여 에너지 고립률은 0.013545–0.989672 범위였다.
같은 팽창 결합에서 랭크 에너지가 입자 에너지보다 먼저, 더 크게 고립되는 경향이 나타났다.
이는 본 모형에서 랭크 대표척도가 더 크고 정보전파 상한이 더 낮게 설정되었기 때문이다.

## 5. 수치감사

시간간격을 0.008, 0.004, 0.002, 0.001 tau로 줄였을 때 균형군의 누적 e-fold는 1.340429, 1.340018, 1.339811, 1.339708로 수렴했다.
최종 입자 고립률과 랭크 고립률도 각각 약 0.3265와 0.9574로 수렴했다.

전체 기준군의 최대 에너지 장부 오차는 5.76e-13 이하였다.

## 6. 이번 계산에서 얻은 새 구분

```txt
국소 랭크 붕괴
!= 전역 연결 랭크 상실

전구조 유출
!= 소산

팽창에 의한 고립
!= 국소 구조의 즉시 소멸

고립된 랭크 에너지
!= 독립 랭크가 계속 유지된다는 보장

형성 사건의 소멸
!= 기초 D3 구조 전체의 소멸
```

특히 `N_local > N_connected` 상태는 기존 붕괴 파이프라인에 없던 결과다.
팽창이 충분히 빠르면 랭크 에너지가 국소 구조에는 남아 있으면서도 전역 교환·기술 가능 채널에서는 먼저 분리될 수 있다.
